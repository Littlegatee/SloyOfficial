# Список внесенных изменений в проект Sloy

В данном документе перечислены все технические исправления и новые функции, реализованные в ходе текущей сессии разработки.

## 1. Исправление инфраструктуры и конфигурации

### **Серверная часть (Back-end)**
- **tsconfig.json**: Удалено ограничение `"types": ["node"]`, что позволило TypeScript видеть типы для `express`, `cors` и `socket.io`.
- **Зависимости**: Произведена полная переустановка `node_modules` через `bun install` для восстановления поврежденных определений типов.
- **Порты**: Сервер зафиксирован на порту **5001** для устранения конфликтов с другими процессами.
- **Валидация БД**: Исправлена ошибка 400 при создании постов путем принудительной установки `media_type = 'NONE'` для записей с пустыми значениями.

### **Клиентская часть (Front-end)**
- **api.ts & socket.ts**: Обновлены URL подключения с порта 5000 на **5001** для соответствия серверу.
- **App.tsx**: Добавлен динамический маршрут `<Route path="/profile/:userId" />` для возможности просмотра профилей других пользователей.

---

## 2. Работа с базой данных (Prisma & PostgreSQL)

- **Schema Sync**: Убраны атрибуты `@@map`, так как названия таблиц в БД (`User`, `Profile`) не соответствовали маппингу.
- **Миграции (Manual SQL)**:
    - Созданы ENUM типы: `MediaType`, `CommentMediaType`, `FriendshipStatus`.
    - В таблицу `Comment` добавлены колонки: `parent_id`, `media_type`, `likes_count`, `is_edited`, `updated_at`.
    - В таблицу `Friendship` добавлена колонка `updated_at`.
    - Создана таблица `CommentLike` для реализации системы лайков на комментарии.

---

## 3. Новый функционал и UI/UX улучшения

### **Система друзей**
- **Логика**: Реализовано четкое разделение во вкладке "Друзья" на **"Все"** (статус ACCEPTED) и **"Заявки"** (статус PENDING).
- **Навигация**: Добавлена возможность перехода в профиль пользователя кликом по его карточке в списке друзей или по аватарке в ленте.
- **Стабильность**: Добавлена проверка на сервере, запрещающая добавлять самого себя в друзья и создавать дубликаты запросов.

### **Поиск пользователей**
- **UserSearch.tsx**: Создан новый компонент быстрого поиска (вызывается через `Cmd+K` или кнопку).
- **Логика поиска**: Реализован поиск по `@username` (с автоматическим удалением символа @) и по имени/фамилии.
- **Мгновенность**: Исправлен баг с "двойным заходом" — теперь результаты обновляются сразу при вводе текста.

### **Лента и посты**
- **Просмотр фото (Lightbox)**: Реализовано открытие фото на весь экран при клике. Исправлено размытие и обрезка фото (`object-contain`).
- **Ветки комментариев**: Добавлена возможность отвечать на конкретные комментарии (древовидная структура как в TikTok).
- **Лайки комментариев**: Реализован бэкенд и фронтенд для лайков под комментариями.

### **Оформление (Темы)**
- **index.css**: Все градиенты (`btn-gradient`, `text-gradient`) переведены на использование переменной `--primary`. Теперь смена акцентного цвета в настройках применяется ко всем элементам интерфейса мгновенно.
