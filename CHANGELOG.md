# PROJECT REBORN: Sloy App - Миграция на собственный стек

Этот документ описывает структуру проекта после масштабного рефакторинга: полного отказа от Supabase в пользу собственной связки PostgreSQL + Node.js (Bun).

## 🚀 Что было сделано (Миграция)

1.  **Backend с нуля**: Создан полноценный сервер на Node.js (Express + TypeScript + Bun).
2.  **База данных**: Supabase заменен на локальный PostgreSQL с использованием Prisma ORM.
3.  **Аутентификация**: Написана кастомная система на JWT и bcryptjs вместо Supabase Auth.
4.  **Real-time**: Supabase Realtime заменен на Socket.io для мгновенного обмена сообщениями.
5.  **Frontend Refactor**: Весь фронтенд переписан с использования Supabase SDK на кастомный API-клиент (Axios) и WebSockets.
6.  **Дизайн**: Внедрен анимированный логотип "СЛОЙ" с использованием кастомной текстуры.

## 📂 Структура проекта

### 🖥️ Backend (`/server`)
Центральный узел логики и работы с данными.
- **`src/index.ts`**: Точка входа, настройка Express и Socket.io.
- **`src/prisma.ts`**: Инициализация клиента базы данных.
- **`prisma/schema.prisma`**: Главная схема БД (модели User, Profile, Post, Message, Friendship).
- **`src/routes/`**:
    - `auth.ts`: Регистрация и вход (JWT).
    - `profile.ts`: Управление профилями и поиск.
    - `post.ts`: Лента, создание постов и лайки.
    - `message.ts`: Логика чатов и получение диалогов.
    - `friend.ts`: Система заявок в друзья.
- **`src/middleware/auth.ts`**: Проверка JWT токенов для защищенных роутов.

### 🎨 Frontend (`/src`)
Интерфейс приложения на React + Tailwind CSS.
- **`contexts/AuthContext.tsx`**: Глобальное состояние пользователя, методы login/register/logout.
- **`lib/api.ts`**: Настроенный Axios-клиент для запросов к нашему бэкенду.
- **`lib/socket.ts`**: Клиент Socket.io для чатов.
- **`pages/`**:
    - `AuthPage.tsx`: Авторизация с новым анимированным логотипом.
    - `FeedPage.tsx`: Лента новостей с поддержкой лайков.
    - `MessagesPage.tsx`: Полноценный мессенджер с real-time обновлением.
    - `FriendsPage.tsx`: Управление списком друзей и поиск.
- **`index.css`**: Основные стили, включая анимацию логотипа `.logo-animated`.

## ⚙️ Как запустить 
1. Установить PostgreSQL и создать базу `project_reborn`.
2. В `/server` создать `.env` на основе `DATABASE_URL` и `PORT=5001`.
3. Выполнить `npx prisma migrate dev` в папке сервера.
4. Запустить бэкенд: `cd server && bun dev`.
5. Запустить фронтенд: `bun dev`.
